# Vincent James G. Postrano — Portfolio

A personal portfolio for Vincent, a third year Computer Science student. The gallery highlights four projects: API Fetch Practice, Task Manager Activity, Medicine Inventory, and Postman Testing.

## Run locally

```sh
npm install
npm run dev
```

Run `npm run build` for a production build and `npm run lint` for code checks.

The first two project summaries are intentionally brief because their repository contents could not be verified while building this site. Medicine Inventory links to its [GitHub repository](https://github.com/zuri-sys/medicine-inventory); Postman Testing links to the [supplied PDF report](/docs/postman-testing.pdf), which documents product API checks and recorded findings. The project visuals are original conceptual illustrations, not screenshots of the projects or report.

The project showcase takes broad inspiration from [John Gearhart's portfolio](https://johngearhart.me/): large editorial titles and an immersive project gallery. The color system, interface illustrations, copy, controls, and page layout are original to this portfolio.
