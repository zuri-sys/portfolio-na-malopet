# Vincent James G. Postrano — Portfolio

A personal portfolio for Vincent, a third year Computer Science student. The site highlights two learning projects and links to their GitHub repositories.

## Run locally

```sh
npm install
npm run dev
```

Run `npm run build` for a production build and `npm run lint` for code checks.

Project summaries are intentionally brief because the linked repository contents could not be verified while building this site. The project visuals are original conceptual illustrations, not screenshots of the repositories.
